Diccionario Técnico

Glosario de todos los términos técnicos del proyecto: dominio, framework, seguridad e infraestructura.

Dominio — Entidades de negocio

Término Definición
Centro Instituto, colegio u organización educativa. Tabla centros. Tiene configuración JSONB.
Curso Académico Año lectivo (ej: 2025-2026). Tabla cursos_academicos. Marca si está activo.
Módulo Asignatura o materia (Programación, BBDD…). Código único. Tabla modulos.
Resultado de Aprendizaje (RA) Objetivo formativo de un módulo ligado a un curso académico. Tiene peso_sugerido. Tabla resultados_aprendizaje.
Criterio de Evaluación (CE) Sub-criterio de un RA. Tiene peso, instrumento y trimestre. Las notas se almacenan a este nivel. Tabla criterios_evaluacion.
Grupo Clase de alumnos en un centro. Tiene un tutor opcional (tutor_id FK → usuarios). Tabla grupos.
Impartición Instancia de un módulo enseñado por un profesor a un grupo en un centro. Une Módulo + Grupo + Profesor + Centro. Tabla imparticiones.
Matrícula Inscripción de un alumno en una impartición. Estados: ACTIVA, BAJA, CONVALIDADO. Campo es_repetidor. Tabla matriculas.
Período de Evaluación Agrupación temporal dentro de una impartición (ej: 1er trimestre). Tiene peso para la nota global. Tabla periodos_evaluacion.
Ítem Evaluable Actividad concreta de evaluación: EXAMEN, PRACTICA, RECUPERACION, ACTITUD. Tabla items_evaluables. Tiene configuracion_rubrica (JSONB).
Calificación Nota de un alumno en un CE. Valor 0-10. Tabla calificaciones. Cada cambio queda en auditoria_notas.
Auditoría de Notas Historial de cambios de calificaciones: valor anterior, nuevo, quién, cuándo. Tabla auditoria_notas. Rellenada por trigger PL/pgSQL.

Framework y stack

Término Definición
Spring Boot Framework Java para aplicaciones web. Versión 3.3.5 con Java 21. Incluye autoconfiguración y servidor embebido.
Spring Security Módulo de autenticación y autorización. Versión 6. Configura login, roles, headers, CSRF y sesión.
Spring Data JPA Abstracción sobre Hibernate para acceso a datos. Repositorios con métodos automáticos y queries JPQL.
Hibernate ORM (Object-Relational Mapping) que traduce entidades Java a tablas SQL. Versión 6.
Thymeleaf Motor de plantillas HTML del lado del servidor. Las variables se insertan con th:text, nunca th:utext para datos de usuario.
Flyway Herramienta de migraciones de base de datos. Los scripts se versionan (V1, V2…) y se aplican al arrancar la app.
MapStruct Generador de código Java para convertir entre entidades y DTOs en tiempo de compilación. componentModel = "spring".
Lombok Reduce boilerplate de Java: genera getters, setters, constructores, etc. mediante anotaciones.
Bean Validation Estándar Jakarta para validar datos con anotaciones (@NotBlank, @Size, @Email…). Los DTOs son Java records.
DTO (Data Transfer Object) Objeto que transporta datos entre capas. En Schooledule son Java records inmutables.
Spring Session JDBC Almacena sesiones HTTP en PostgreSQL (tabla SPRING_SESSION). Sobrevive reinicios.
Bootstrap 5 Framework CSS para la interfaz. Se usa junto a los estilos propios del design system.

Seguridad

Término Definición
RBAC Role-Based Access Control. Control de acceso por roles. En Schooledule: ADMIN, ADMIN_CENTRO, PROFESOR, ALUMNO.
BCrypt Algoritmo de hash para contraseñas con salt. Unidireccional: no se puede desencriptar. Spring usa BCryptPasswordEncoder.
CSRF Cross-Site Request Forgery. Ataque que fuerza peticiones no deseadas. Prevenido con token CSRF en formularios (Thymeleaf lo integra automáticamente).
CSP Content Security Policy. Cabecera HTTP que restricte qué recursos puede cargar el navegador. Previene XSS. En Schooledule: default-src 'self'; frame-ancestors 'none'.
XSS Cross-Site Scripting. Inyección de JS malicioso. Prevenido con th:text (escapa HTML) y la cabecera CSP.
SQL Injection Inyección de SQL malicioso. Prevenido usando JPA con consultas parametrizadas, nunca concatenación de strings.
Session Fixation Ataque donde el atacante conoce el ID de sesión antes del login. Mitigado con changeSessionId() al autenticar.
@PreAuthorize Anotación de Spring Security que aplica control de acceso por rol a nivel de clase o método. Segunda barrera tras las reglas URL.
Bucket4j Librería Java de rate limiting basada en algoritmo Token Bucket. Usada en LoginRateLimitFilter: 10 req/15 min por IP.
OWASP Top 10 Lista de los 10 riesgos de seguridad más críticos en aplicaciones web, publicada por OWASP. Edición 2021.
snap-admin Librería eliminada (v0.2.1). Exponía panel CRUD de todas las entidades JPA sin autenticación. Severidad CRÍTICA (A06).

Base de datos y persistencia

Término Definición
PostgreSQL 16 Base de datos relacional utilizada. Soporta JSONB, PL/pgSQL y tipos personalizados (enums).
JSONB Tipo de dato PostgreSQL para JSON binario. Más eficiente que JSON. Usado en configuracion_evaluacion (imparticiones) y configuracion_rubrica (items).
PL/pgSQL Lenguaje procedural de PostgreSQL para funciones y triggers. Sintaxis similar a Pascal/Ada.
Trigger Función que se ejecuta automáticamente ante un evento. trigger_auditoria_notas: AFTER UPDATE en calificaciones → inserta en auditoria_notas.
app.usuario_actual Variable de sesión PostgreSQL. El servicio la inyecta con set_config('app.usuario_actual', email, true) para que el trigger sepa quién modificó una nota.
H2 Base de datos en memoria usada en tests de integración. No se usa en producción.
Flyway Migration Script SQL versionado (V1__, V2__…). Flyway los aplica en orden al arrancar y registra qué versiones están aplicadas en la tabla flyway_schema_history.

Infraestructura y CI/CD

Término Definición
Docker Plataforma de contenedores. La app se empaqueta con su JRE y se distribuye como imagen.
Docker Compose Herramienta para orquestar múltiples contenedores. Dev: 4 servicios. Prod: 2 servicios.
Multi-stage Dockerfile Dockerfile con varias etapas (FROM). Permite separar build (Maven pesado) de runtime (JRE ligero).
GitHub Actions Servicio CI/CD de GitHub. Los workflows se definen en .github/workflows/*.yml. Schooledule tiene 2: ci-cd.yml y memoria-pdf.yml.
JaCoCo Java Code Coverage. Mide el porcentaje de código cubierto por tests. Umbral mínimo: 80% en Schooledule.
SonarQube Plataforma de análisis estático de código. Detecta bugs, vulnerabilidades y code smells. Solo en entorno dev.
Spotless Plugin Maven para formatear código Java automáticamente (Google Java Format). Pre-commit hook + CI.
Prettier Formateador de HTML, CSS, JS. Pre-commit hook + CI.
Hadolint Linter de Dockerfiles. Verifica buenas prácticas. Usado en el job de lint del CI.
Actionlint Linter de workflows de GitHub Actions. Verifica sintaxis y semántica de los ficheros YAML de CI.
Purge & Promote Flujo automático que crea la rama pre-prod eliminando archivos de desarrollo antes de ir a producción.
Token Bucket Algoritmo de rate limiting: "bucket" que se llena de tokens a una tasa fija. Cada petición consume un token. Sin tokens → petición rechazada.

Patrones y arquitectura

Término Definición
MVC Model-View-Controller. Patrón arquitectónico. En Spring Boot: Controller (peticiones HTTP) + Service (lógica de negocio) + Repository (acceso a datos) + Thymeleaf (vista).
Multi-tenant Arquitectura donde varios clientes (centros) comparten la misma instancia de la app con datos aislados por centro_id.
TDD Test-Driven Development. Metodología: primero el test (Red), luego el código (Green), luego refactor. Obligatorio en Schooledule.
IDOR Insecure Direct Object Reference. Acceder a datos ajenos cambiando un ID en la URL. Prevenido con ownership checks en servicios.
Defense in depth Múltiples capas de seguridad independientes. En Schooledule: URL rules + @PreAuthorize + ownership checks en servicio.
