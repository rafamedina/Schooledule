Autenticación

Página de Selección de Rol

Pantalla intermedia que aparece cuando un usuario autenticado tiene más de un rol funcional asignado.

¿Cuándo aparece esta página?

Tras un login exitoso, CustomLoginSuccessHandler cuenta los roles funcionales del usuario (ROLE_ADMIN, ROLE_ADMIN_CENTRO, ROLE_PROFESOR, ROLE_ALUMNO). Si hay más de uno, redirige a /seleccionar-rol en lugar de ir directamente al dashboard.

Login exitoso → CustomLoginSuccessHandler → ¿roles > 1? → Sí → /seleccionar-rol

Tarjetas de rol

La plantilla Thymeleaf usa th:if="${roles.contains('ROLE_XXX')}" para mostrar solo las tarjetas de los roles que tiene el usuario:

✦ Administrador

Gestión de infraestructura, usuarios y centros educativos.

Destino: /admin/dashboard

■ Admin de Centro

Gestión de usuarios, grupos e imparticiones de tus centros asignados.

Destino: /centro-admin/dashboard

✎ Profesor

Gestión de grupos, evaluaciones y seguimiento de alumnos.

Destino: /profe/dashboard

⚒ Alumno

Consulta de calificaciones, horarios y expediente académico.

Destino: /alumno/dashboard

Al pie de la página hay un formulario de Cerrar sesión (POST /logout) que el usuario puede usar para salir sin entrar a ningún portal.

Implementación Thymeleaf

<!-- Ejemplo: tarjeta de Admin -->
<a href="/admin/dashboard"
   class="role-card animate-in"
   th:if="${roles.contains('ROLE_ADMIN')}">
  <div class="role-card__icon">✦</div>
  <span class="role-card__name">Administrador</span>
  <p class="role-card__desc">...</p>
</a>

Si el usuario solo tiene un rol, esta página no se muestra. La condición se evalúa sobre el modelo (roles) que el controlador de autenticación inyecta en la sesión.

Seguridad de la página

Atención: Una vez en /seleccionar-rol, el usuario sigue autenticado. Si accede directamente a /admin/dashboard sin pasar por la selección, SecurityConfig comprueba el rol mediante hasRole("ADMIN"). Solo puede acceder si el usuario tiene ese rol asignado.

No es posible "elegir" un rol que el usuario no tiene: los th:if de Thymeleaf y las reglas de SecurityConfig son independientes y ambas aplican.

Preguntas frecuentes

¿Cuándo aparece la página de selección de rol?

Solo cuando el usuario tiene más de un rol funcional (ADMIN, ADMIN_CENTRO, PROFESOR, ALUMNO). Si solo tiene uno, CustomLoginSuccessHandler redirige directamente al dashboard correspondiente.

¿Qué pasa si un usuario con ROLE_ADMIN y ROLE_PROFESOR hace login?

Ve la página de selección con dos tarjetas: "Administrador" y "Profesor". Elige con cuál quiere trabajar en esa sesión.

¿Puede un usuario acceder a un portal para el que no tiene rol?

No. Aunque conozca la URL, SecurityConfig bloquea el acceso a /admin/** si no tiene ROLE_ADMIN, etc. Recibe 403 Forbidden.
