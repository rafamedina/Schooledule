Importación masiva de usuarios (Excel)

El controlador AdminUsuarioImportController usa el servicio UsuarioPlantillaExcelService para procesar ficheros .xlsx.

9 columnas en la plantilla Excel, incluyendo es_repetidor. El sistema crea usuarios, les asigna rol, centro, grupo y matrícula en una sola operación.

El servicio valida cada fila, reporta errores por fila y solo persiste las válidas. No hace rollback parcial: las filas válidas se guardan aunque otras fallen.

Jerarquía de entidades que gestiona

Centro → CursoAcadémico → Grupo → Impartición → Matrícula + Notas
Módulo → RA → CE (estructura de evaluación)

Auditoría global

AdminAuditoriaController muestra el contenido de la tabla auditoria_notas con todos los cambios de calificaciones del sistema.

Cada registro incluye: calificacion_id, valor_anterior, valor_nuevo, usuario_responsable (email del profesor), fecha_cambio y motivo opcional.

Layout del portal

El portal admin usa un layout de sidebar lateral (no topnav). La clase CSS es .admin-sidebar con fondo oscuro (var(--ink)) y el logo en blanco (schooledule-logo-white.svg). El contenido principal está en .admin-main.

Preguntas frecuentes

¿Cuántos controladores tiene el portal de administrador?

11 controladores: AdminController (dashboard), AdminCentroController, AdminUsuarioController, AdminCursoController, AdminGrupoController, AdminModuloController, AdminImparticionController, AdminAlumnoController, AdminUsuarioImportController, AdminModuloImportController y AdminAuditoriaController.

¿Cómo funciona la importación masiva de usuarios?

El admin sube un fichero Excel con 9 columnas. UsuarioPlantillaExcelService valida cada fila y persiste las válidas. Se pueden crear usuarios, asignarles rol, centro, grupo y matrícula en bloque.

¿Qué es la tabla auditoria_notas?

Registra cada cambio de calificación: valor anterior, valor nuevo, quién lo hizo (usuario_responsable) y cuándo. Se rellena automáticamente por el trigger PL/pgSQL trigger_auditoria_notas cuando hay un UPDATE en calificaciones.
