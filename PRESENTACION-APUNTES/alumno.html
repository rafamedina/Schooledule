Portal Alumno

Acceso de estudiantes a sus calificaciones, asignaturas matriculadas y perfil. Solo puede ver sus propios datos.

Datos clave

Rol requerido
ROLE_ALUMNO
URL base
/alumno/**
Controlador
AlumnoController

Páginas disponibles

Ruta Tipo Descripción
/alumno/dashboard GET Web Lista de asignaturas en las que está matriculado (imparticiones activas)
/alumno/perfil GET Web Datos del alumno, estado de matrícula, centro
/alumno/notas GET Web Vista de calificaciones por asignatura y período (renderizado servidor)
/alumno/api/matricula/{id}/notas GET JSON Devuelve las notas detalladas de una matrícula en formato JSON. Solo si el id pertenece al alumno autenticado.
Seguridad de propiedad: Si un alumno intenta acceder a la matrícula de otro alumno por la API, recibe 401 Unauthorized. El servicio valida que matricula.alumnoId == usuario_autenticado.id.

Estados de matrícula

Cada alumno tiene una Matricula por cada Imparticion. Los estados posibles son:

ACTIVA

El alumno está cursando la asignatura normalmente.

BAJA

El alumno ha causado baja en esa asignatura.

CONVALIDADO

La asignatura ha sido convalidada por estudios previos o traslado.

El campo es_repetidor (booleano) indica si el alumno repite la asignatura ese curso.

Jerarquía de calificaciones

Las notas se almacenan a nivel de Criterio de Evaluación (CE) y se agregan hacia arriba con pesos:

Calificacion (CE) → Resultado Aprendizaje (RA) (peso CE) → Período Evaluación (pesoSugerido RA) → Nota Global (peso Período)
Si todos los pesos de un nivel son 0, se usa media simple como fallback para evitar división por cero.

Modelo de datos relevante

Entidad Tabla Campos clave
Matricula matriculas alumno_id, imparticion_id, centro_id, es_repetidor, estado (enum)
Imparticion imparticiones modulo_id, grupo_id, profesor_id, centro_id
Calificacion calificaciones matricula_id, criterio_evaluacion_id, valor (0-10), comentario
CriterioEvaluacion criterios_evaluacion resultado_aprendizaje_id, codigo, peso, instrumento, trimestre

Preguntas frecuentes

¿Qué ocurre si un alumno intenta ver las notas de otro alumno?

El servicio comprueba que la matrícula pertenezca al alumno autenticado. Si no, devuelve 401. Además, @PreAuthorize garantiza que solo usuarios con ROLE_ALUMNO accedan a /alumno/**.

¿Cuáles son los estados de matrícula?

ACTIVA, BAJA y CONVALIDADO. Es un enum PostgreSQL (estado_matricula). No existe el estado TRASLADO.

¿Cómo se calcula la nota final de un módulo?

Se agregan las calificaciones de CE con el peso de cada CE para obtener la nota del RA. Los RAs se ponderan con peso_sugerido para el período. Los períodos se ponderan con su peso para la nota global. Si todos los pesos son 0, se aplica media simple.

¿Qué endpoint JSON usa el alumno para ver sus notas?

GET /alumno/api/matricula/{matriculaId}/notas — devuelve JSON con las notas detalladas. Solo funciona si la matrícula pertenece al alumno autenticado.

¿Qué significa es_repetidor?

Es un campo booleano en matriculas que indica si el alumno está cursando esa asignatura por segunda vez o más. Se puede importar en el Excel de usuarios.
